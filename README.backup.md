# developer-os

Plataforma personal de productividad y gestión inteligente para desarrolladores y estudiantes. Centraliza proyectos, tareas, estudio, documentación, objetivos y métricas en un único espacio, con automatización e integración con servicios externos.

Objetivo

Construir una plataforma Full-Stack escalable que permita organizar y analizar el trabajo y aprendizaje del usuario, convirtiendo sus datos de actividad en información útil para la toma de decisiones.

Funcionalidades

- Dashboard personalizado
- Gestión de proyectos
- Gestión de tareas y prioridades
- Organización de materias y sesiones de estudio
- Seguimiento de objetivos
- Gestión de documentos y recursos
- Métricas de productividad y aprendizaje
- Integración con GitHub
- Autenticación de usuarios
- Control de acceso mediante Row Level Security
- Automatizaciones
- Funcionalidades basadas en IA

Tecnologías

- React
- TypeScript
- Vite
- Supabase
- PostgreSQL
- Tailwind CSS
- GitHub
- Vercel
